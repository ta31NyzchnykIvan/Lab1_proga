# Локальний PHP API та Python клієнт

Цей проєкт містить простий локальний API на PHP, який повертає JSON-дані з файлу, та консольний клієнт на Python, який зчитує ці дані через локальний HTTP-запит.

Інструкція:

1) Запустіть вбудований PHP-сервер з кореня проєкту:

   php -S localhost:8000 -t public

2) У іншому терміналі запустіть Python-клієнт:

   python3 client.py

За замовчуванням клієнт робить запит до http://localhost:8000/data і виводить форматований JSON.

Файл з даними знаходиться в data/items.json. Також додано data/data.txt із текстовим описом набору даних.

Якщо потрібен автозавантажувач Composer, виконайте:

   composer install
